# Release Packaging Design

## Overview

Replace the manual cross-compilation release workflow with GoReleaser to support three distribution channels: Homebrew (macOS), deb/rpm packages (Linux), and a universal install script.

## Distribution Channels

### 1. Homebrew Tap

- New repo: `slayer/homebrew-gcon`
- GoReleaser auto-pushes formula updates on each tag release
- Formula downloads correct archive per platform, verifies SHA256

```bash
brew tap slayer/gcon
brew install gcon
# or one-liner:
brew install slayer/gcon/gcon
```

### 2. Deb + RPM Packages

- Generated by GoReleaser's nFPM integration
- Published as GitHub release artifacts
- Installs binary to `/usr/bin/gcon`

```bash
# Download and install deb
curl -LO https://github.com/slayer/gcon/releases/download/v0.6.0/gcon_0.6.0_amd64.deb
sudo dpkg -i gcon_0.6.0_amd64.deb

# Download and install rpm
curl -LO https://github.com/slayer/gcon/releases/download/v0.6.0/gcon_0.6.0_amd64.rpm
sudo rpm -i gcon_0.6.0_amd64.rpm
```

### 3. Install Script

- `install.sh` in the main repo
- Detects OS/arch, fetches latest release, verifies checksum, installs binary
- Falls back to `~/.local/bin` without sudo

```bash
curl -sSL https://raw.githubusercontent.com/slayer/gcon/master/install.sh | bash
# or specific version:
curl -sSL https://raw.githubusercontent.com/slayer/gcon/master/install.sh | bash -s -- v0.6.0
```

## GoReleaser Configuration

### Builds

- 5 targets: macOS (amd64/arm64), Linux (amd64/arm64), Windows (amd64)
- Ldflags: `-s -w -X main.version={{.Version}} -X main.commit={{.ShortCommit}} -X main.date={{.Date}}`
- Binary name: `gcon`

### Archives

- Tar.gz for macOS/Linux, zip for Windows
- Named `gcon_{{.Version}}_{{.Os}}_{{.Arch}}`

### Packages (nFPM)

- Deb and RPM formats
- Architectures: amd64, arm64
- Installs to `/usr/bin/gcon`

### Homebrew

- Auto-updates formula in `slayer/homebrew-gcon`
- Requires PAT with `repo` scope stored as `HOMEBREW_TAP_TOKEN` secret

### Checksums

- SHA256 checksums file for all artifacts

## GitHub Actions Changes

### release.yml (rewrite)

- Trigger: push of tags matching `v*`
- Steps: checkout (full history) -> setup Go 1.24 -> run tests -> GoReleaser
- GoReleaser needs `GITHUB_TOKEN` (release creation) and `HOMEBREW_TAP_TOKEN` (tap push)

### ci.yml (update)

- Bump Go version from 1.22 to 1.24 to match go.mod

## Code Changes

### cmd/gcon/main.go

Add version variables for linker injection:

```go
var (
    version = "dev"
    commit  = ""
    date    = ""
)
```

Add `--version` / `-v` flag:

```
gcon version dev (commit: abc1234, built: 2026-03-25)
```

### Makefile

- Update `build` target to embed version from `git describe --tags --always`
- Remove `build-all` target (GoReleaser handles cross-compilation)
- Keep `run`, `dev`, `test`, `lint` targets unchanged

## Files Changed

| File | Action | Description |
|------|--------|-------------|
| `cmd/gcon/main.go` | Modify | Add version variables + `--version` flag |
| `.goreleaser.yaml` | Create | Full GoReleaser config |
| `.github/workflows/release.yml` | Rewrite | Replace manual builds with GoReleaser |
| `.github/workflows/ci.yml` | Modify | Bump Go version to 1.24 |
| `Makefile` | Modify | Version embedding, remove `build-all` |
| `install.sh` | Create | Universal install script |

## Prerequisites

1. Create `slayer/homebrew-gcon` GitHub repo
2. Create PAT with `repo` scope
3. Add `HOMEBREW_TAP_TOKEN` secret to `slayer/gcon` repo settings
